# experiments — 보고서 수치의 재현 스크립트와 결과 요약

| 폴더 | 데이터 | 용도 | 대표 결과 |
|---|---|---|---|
| gold300/ | 제공 데이터 300장(규칙 조정용) | 검출 임계값 7조합, 사다리 V0~V6, 판별기 R0~R4 비교 | V6+R4 264/300 (88.0%) — 규칙 설계·후보 선택에 사용된 집합 |
| custom100/ | 자체 촬영 100장 | 미열람 1차 검증 | 92/100 (92.0%), 오탐 0 |
| unseen300/ | 제공 데이터 중 미사용 300장 | 미열람 2차 검증(규칙 동결 후 1회 개봉) | 254/300 (84.7%), 칸 89.0%, 오탐 1, 2.24초/장 |

- 현행 코드는 저장소 루트의 `src/`이며, `sweep.py`는 루트 `src/`를 import한다. `gold300/resolvers/r0_github_backup.py`는 예선 제출본 판별기(비교 기준)이다.
- 이미지는 용량 문제로 포함하지 않는다. 각 폴더의 `gold_*.csv`가 정답 라벨이고, 제공 데이터의 image_id로 원본을 찾을 수 있다. 재현: `images/`에 이미지를 넣고 `python sweep.py --name <이름> --workers 4 --budget 16.8`.
- `results/*.summary.json`은 설정별 요약, `results/*.jsonl`은 이미지별 결과(OCR 원문 포함)이다.
